# Space Invaders 3D

A 3D recreation of the classic Space Invaders arcade game built with Odin and raylib.

## Features

- 3D graphics using raylib
- Classic Space Invaders gameplay mechanics
- Player ship with shooting capabilities
- Enemy invaders with AI movement patterns
- Score tracking
- Sound effects

## Requirements

- Odin compiler
- raylib library

## Building

```bash
./build.sh
```

## Running

```bash
./space_invaders_3d
```

## Controls

- **Arrow Keys / A/D**: Move ship left/right
- **Space**: Shoot
- **ESC**: Exit game

## Game Rules

- Destroy all enemy invaders before they reach your position
- Avoid enemy projectiles
- Score points for each enemy destroyed
- Game over if enemies reach the bottom or you get hit
